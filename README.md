# 📚 Library Management System  
**JavaFX & PostgreSQL Desktop Application**

---

## 📌 Project Overview

The **Library Management System** is a desktop-based application developed using **Java** and **JavaFX**, integrated with a **PostgreSQL** database.  
The application is designed to manage library book data efficiently through a clean and modern graphical user interface.

This project demonstrates:
- Object-Oriented Programming (OOP)
- JavaFX GUI development
- PostgreSQL database integration using JDBC
- MVC (Model–View–Controller) architecture

---

## 🎯 Features

- 📖 Add new books  
- 📋 View all books in a table  
- 🔄 Borrow / Return books  
- ❌ Delete books  
- 🔍 Search books by title or author  
- 🎨 Modern JavaFX UI with CSS  

---


## 🛠️ Technologies Used

| Category | Technology |
|--------|-----------|
| Language | Java |
| GUI | JavaFX |
| Database | PostgreSQL |
| Access | JDBC |
| Styling | JavaFX CSS |

---

## ▶️ How to Run

1. Add PostgreSQL JDBC driver
2. Start PostgreSQL  
3. Create database & table  
4. Add dummy data to the table  
5. Run `Main.java`
